# Week 8 — Project structure

Open `react_native_intro/` in your editor. Compare with `task_manager_app/` or `tap_rush_game/` from Flutter weeks.

## Side-by-side (high level)

| Purpose | Flutter | React Native (this repo) |
|---------|---------|---------------------------|
| Entry | `lib/main.dart` | `index.js` → `App.tsx` |
| App root widget | `MaterialApp` / `TapRushApp` | `App` + `HomeScreen` |
| Screens / pages | `lib/..._screen.dart` | `src/screens/HomeScreen.tsx` |
| Reusable UI | `lib/widgets/...` | `src/components/*.tsx` |
| Dependencies | `pubspec.yaml` | `package.json` |
| Lock file | `pubspec.lock` | `package-lock.json` (gitignored in this course repo) |
| Native Android | `android/` | `android/` |
| Native iOS | `ios/` | `ios/` |
| Dev server | `flutter run` (built-in) | `npm start` (Metro) + `npm run android` |

## Tree you should recognize

```text
react_native_intro/
├── App.tsx              ← Root component (start reading here)
├── index.js             ← Registers app name with OS
├── package.json         ← npm dependencies & scripts
├── app.json             ← Display name for packager
├── babel.config.js      ← JS compiler config
├── metro.config.js      ← Bundler config
├── src/
│   ├── screens/
│   │   └── HomeScreen.tsx
│   └── components/
│       ├── WelcomeHeader.tsx
│       ├── LessonCard.tsx
│       ├── PrimaryButton.tsx
│       └── CounterDemo.tsx
├── android/             ← Gradle — do not edit much in Week 8
└── ios/                 ← Xcode — optional this week
```

## Key files explained

### `index.js`

Registers the root component with React Native:

```javascript
AppRegistry.registerComponent(appName, () => App);
```

Flutter equivalent: `void main() { runApp(const MyApp()); }`

### `App.tsx`

Top-level wrapper (SafeArea, StatusBar) and chooses the first screen:

```typescript
<HomeScreen />
```

### `src/screens/HomeScreen.tsx`

One full page — layout of header, cards, counter, footer.  
Flutter equivalent: a `Scaffold` with `body: Column(...)`.

### `src/components/*.tsx`

Small, reusable pieces. Each file exports **one** function component.  
Flutter equivalent: `StatelessWidget` classes in separate files.

### `package.json` scripts

| Script | What it does |
|--------|----------------|
| `npm start` | Start Metro |
| `npm run android` | Build & install Android debug app |
| `npm run ios` | Build & run iOS simulator |
| `npm test` | Jest unit test (smoke test on `App`) |

## What to avoid editing on day one

- `android/gradle` versions (unless instructor guides a fix)
- `ios/Podfile` (unless doing iOS setup)
- `node_modules/` (always regenerated by `npm install`)
