# TVEC / LMS — MCQ examination pack

Formal MCQ materials for submitting student marks through the **LMS** to **TVEC**.

| File | Audience | Use |
|------|----------|-----|
| `mobile-dev-mcq-student-paper.md` | Students | Examination paper (no answers) |
| `mobile-dev-mcq-instructor-pack.md` | Lecturer / assessor | Answer key, marking, outcome map |
| `mobile-dev-mcq-lms-import.csv` | LMS admin | Bulk upload template (Moodle-style) |

## Before the exam

1. Confirm your institution’s LMS import format (CSV columns may differ).
2. Fill in **blank fields** on the cover block: NVQ level, unit code, batch, date, duration.
3. Enter the same **40 questions** in the LMS question bank (or import CSV).
4. Set pass mark and time limit in LMS to match the instructor pack.

## If your TVEC circular differs

Send the official guideline (page or PDF) and update:

- Number of options (if not A–D)
- Negative marking (yes/no)
- Required header fields
- Competency unit codes
